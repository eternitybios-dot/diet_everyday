# トレ飯

React + TypeScript + Viteで動く、トレーニング・食事・体重の記録アプリ。
データはブラウザ内に保存され、サーバー同期は行いません。

## 開発

Node.js 22.13以降を推奨します。`npm ci` → `npm run dev` で起動します。
`npm test` で回帰テスト、`npm run build` で型チェックと本番ビルドを実行します。
PRではテスト・ビルドだけを実行し、mainの既存DeployワークフローがGitHub Pagesに公開します。

## 記録を守る仕組み

- 既存の `tremeshi-v2` / `tremeshi-v1` 保存形式を継続利用します。
- 起動時に読み込みが失敗しても、空の初期値で元データを上書きしません。
- 読み込みエラー時は自動保存を停止。警告の「元データを救出」で元の文字列をダウンロードできます。
- 保存容量不足・保存禁止時はエラーを表示し、画面の記録を書き出すか保存を再試行できます。
- 設定からバックアップを読み込む際は、形式・数値・日付・重複IDを確認し、件数を表示して置き換えを確認します。
- 読み込みで既存データは置き換わります。適用前に現在のデータを書き出してください。
- 未対応の将来バージョン、不正な記録、10MBを超えるファイルは取り込みません。破損行を黙って捨てることはしません。
- 空の体重履歴にサンプル測定値を追加しません。過去日の体重を追加・修正しても最新日の体重をプロフィールに保ちます。

## キャッシュ

Service Workerのキャッシュ名はアプリの公開URLごとに分離しています。
キャッシュの更新で、同じGitHub Pagesドメインにある別アプリのキャッシュを削除しません。
オフラインでは閲覧済みのページ・資産のみ利用できます。完全な事前キャッシュは行っていません。

## 検証範囲

Nodeテストで保存・復旧・旧形式移行・入力検証・体重履歴・検索・Service Workerを確認します。
Reactの保存処理はjsdom上でStrictModeを含め確認します。実機Safariの表示、ダウンロード、Service Worker更新、バックグラウンド復帰は別途実機確認が必要です。
この改善では栄養・運動の計算式や既存種目画像を変更していません。カロリー等の表示は推定値です。
